# SenciumLab · 文献星图

付亚鹏的个人文献库网站，以健康经济学、产业组织与公共经济学为主。每篇文献都有依据全文写成的中文简介（标注原文页码）、道法势术器评分与读书笔记，文献之间按库内引用和内容相近连成一张星图。

**网址：<https://fyapeng.com/senlab/>**

## 能看到什么

- **文献星图**：每篇文献是一颗星，颜色是所属星宿（研究主题），亮度是库内中心度，连线是库内引用；可以按发表年或收录时间回放。
- **十二星宿**：每个主题一页，包括代表作（距星）、年份轴、按年代排列的阅读时间线，以及 AI 写的综述与文献分歧。星宿之间的引用往来画成一张关系图。
- **文库**：全部文献的表格，可检索、筛选和排序。
- **论文页**：书目、简介、笔记、评分雷达、关联文献和同主题的上下篇。
- **前沿**：五大期刊（AER、JPE、QJE、REStud、Econometrica）今年以来的文章与本周 NBER 工作论文中，与本库紧密或相关、尚未收录的文章。
- **探索实验室**：
  - 全景：领域发文与本库收藏的热度对照、方法覆盖、主题演化、星宿间引用、桥梁文献；
  - 工具：引用路径、评分象限、方法工具箱；
  - AI 研读：星宿综述、中国情境研究设想、分歧地图。

## 数据从哪里来

书目来自 Zotero，摘要、参考文献与被引来自 OpenAlex、Crossref 和 Semantic Scholar；文献网络、星宿和中心度由程序计算，星宿由人工划定。前沿数据来自两个姊妹项目：[NBER Weekly](https://fyapeng.com/nber/) 与 [Top 5 Journals](https://fyapeng.com/top5papers/)。实验室生成层由 DeepSeek 依据本库公开内容写成，页面上标明「AI 生成」、模型与日期。

简介与笔记是个人阅读记录，评分是个人判断；引用请回到原文。

## 本仓库

只包含站点源码（Astro）和导出的公开数据：书目、属性、简介、评分与评分说明、公开笔记、指标、关联与生成层内容。不含 PDF、全文、本地路径或私密笔记。数据由私有仓库中的流水线生成后推送到这里，`main` 分支更新后由 GitHub Actions 构建并发布到 GitHub Pages。

本地预览：

```bash
npm ci
npm run dev    # http://localhost:4321/senlab/
```
